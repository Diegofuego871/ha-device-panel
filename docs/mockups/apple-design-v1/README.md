# Mockups nach dem Skill "apple-design" (2026-10-10)

Wunsch: Zeigen, wie sich das Design nach dem Skill "apple-design" (Emil Kowalski, abgeleitet aus Apples
WWDC-Vorträgen, installiert unter `.claude/skills/apple-design/`) ändern würde. Im echten Panel (Nachbau), erfundene Daten;
die Varianten hängen nur Stile an die bestehenden Klassen.

- `1-Liste.png`, `2-Geraete-Popup.png`, `3-Einstellungen.png`: je Heute, A Dezent, B Material, C Gruppiert.

Was Bilder nicht zeigen (Teil des Skills, nicht der Mockups): Federn statt fester Dauer, Ziehen des Blatts mit
Schwung und Abbruch mitten in der Bewegung, Blatt, das aus dem Auslöser wächst, reduzierte Bewegung und Transparenz.

Neu rendern: `CHROMIUM_PATH=... node docs/mockups/apple-design-v1/src/render.mjs`
